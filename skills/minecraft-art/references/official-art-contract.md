# 中国版贴图与序列帧制作合同

依据网易开发文档《贴图规范及九宫格使用》《中国版序列帧配置文件解析》，本地可检索固定版本的全文。官方入口：
- https://mc.163.com/dev/mcmanual/mc-dev/mcguide/16-美术/50-贴图规范及九宫格使用.html
- https://mc.163.com/dev/mcmanual/mc-dev/mcguide/16-美术/9-特效/90-中国版序列帧配置文件解析.html

以下为开发约束的归纳，不代替目标版本文档正文。区分文档建议、格式约束与 SparkCraft 当前制作能力。

## UI 和常规纹理

文档建议图像尺寸采用二次幂，减少非标准尺寸引发的内存浪费；推荐限制大纹理使用数量。原版物品图标是 16×16，规则 UI 边框可采用 16×16；更多细节才需要扩大尺寸。模型特效纹理通常建议控制在 128×128，不能把这条推荐误读为所有序列帧图集硬性只能 128×128。

九宫格优先采用文档建议的原生拉伸处理。边距依次为 left、top、right、bottom；四角不缩放，水平边只横向伸展，垂直边只纵向伸展，中心双向伸展。边距不能为负，左右之和须小于图宽，上下之和须小于图高，确保存在中心区域。检查宽屏、窄屏和 UI 缩放时的边线与尖角，避免设计成只能在单一尺寸工作。

## 序列帧资源

PNG 图集与同名 JSON 共同描述动画帧。JSON 有 frames、meta，帧数据必须准确指向图集矩形；Texture Packer 配置为不允许 rotation，Trim mode 为 None，确保子图大小一致。文档示例含九幅子图，实际帧数按动作需要决定。文档列出单张序列帧贴图不超过 512×512、总像素预算不超过 512×512×5；不要为了“更清晰”无依据扩大图集。

资源路径以项目结构为准，文档示例将图集和对应 JSON 放在 textures/picture/sfxs 下。编辑器还会生成额外效果配置，其中 texture 关联图集 JSON。程序端创建所用 effects 路径与纹理路径是不同层级的引用，不可以把 PNG 路径直接冒充所有 SDK 创建接口的参数。

编辑器参数包括 face_camera、fps、shuffle、layer、lerp_scale、loop、rot_speed、scale、tex_repeat_num；环状效果额外涉及 cylinder_enable、cylinder_frac_num、cylinder_height、cylinder_radius_down、cylinder_radius_up。只填写任务需要且格式有依据的字段。图层文档范围为 0–15；是否循环和是否面向镜头取决于场景。单帧 scale 可支持缩放插值，关闭插值需核对 lerp_scale。

## 制作与程序交接清单

每个资源报告：ID、用途、PNG 路径、图集 JSON 路径、效果配置路径（若有）、尺寸、帧数、fps、循环、触发、停止/回收方式。程序必须使用实际产物的 ID 和路径，不能自行改名后留下悬空引用。清点图集中的所有帧，检查未裁边、未旋转、矩形不越界、帧序明确、PNG 含有效透明像素；最后把资源文件与行为脚本一同检查。

若图集由 SparkCraft 像素渲染器生成，应标注该生成方式，不能声称实际运行了 Texture Packer。宿主输出兼容格式仍需在目标客户端验证；对特效配置中的截图字段，应打开原始文档图示核对，不从缺失 OCR 文本猜造格式。
