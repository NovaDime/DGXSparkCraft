# 连接前提

适用于操作者准备连接 Spark 或排查连接条件。项目需求真值见仓库根目录的 `docs/spark-connection-requirements.md`（SP-01 至 SP-08），实际接入步骤见 `docs/spark-connection.md`。

取得主机地址、SSH 端口、账号、主机指纹、认证方式、项目与工作区路径、Gateway 和模型服务信息。缺失项留空并报告；不能根据截图推断账号、30081 端口或某一模型型号。两台 Spark 和 sshpass 是截图示例，本项目最终仍只用一台 Spark。

在已有连接授权内进行 SSH 只读预检，核对目标主机身份、系统架构、版本与所需目录。不要为了连接而关闭主机指纹校验。认证失败应报告失败类型，不显示密码、私钥或 Token。没有目标连接信息时只完成静态检查，不扫描网段猜测设备。

同机运行时 Python 调用 Spark 上的回环 Gateway，Gateway 再连接本机推理服务和策划云端 API。开发机访问网页可使用经核对的 SSH 转发，转发端口需检查占用。模型权重、量化和服务端点尚未选定时不能将 provider/model 示例当作已部署模型。

需要的凭证分别属于 SSH、Gateway 和云端 provider，不互相替代，不交给会议中的五个角色。只记录凭证来源或环境变量名称。连接成功后进入配置准备；连接成功本身不等于模型或 Skill 已验收。
