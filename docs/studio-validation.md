## 当前边界

- 没有运行网易游戏客户端或目标 Python 2.7；校验是静态筛查，不能据此声称模组已游戏验收。
- 生成文本代码和配置，不生成贴图、音频、二进制资源；隐藏目录与秘密文件不会导入。不会执行上传脚本、自动安装依赖或运行 Git hooks。
- 本地路径导入当前针对这台 Linux Spark；Windows 使用浏览器 ZIP 上传或另行适配目录扫描器。
- 原五角色圆桌使用同一推理队列；真实模型仍可能输出不合协议、超时或审查遗漏，任务会保留失败或待人工处理状态。
- 学习是检索与有证据的经验回流；没有训练模型权重、自动改写技能或测得能力提升比例。历史快照保留并占用磁盘。
- 原始源码在独立输出工作区之外。任务终止后不会自动重新覆盖 VS Code 中的人工修改；迭代时导入修订工程作为下个任务的参考。

代码在本地分支 `feat/hackathon-development-studio`，尚未推送 GitHub。
