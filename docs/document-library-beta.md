# 跨游戏资料库（测试版 · 开发中）

在 `/studio` →「代码库与知识」中使用「跨游戏资料」。填写游戏和 SDK 版本，选择粘贴正文、单页 HTTPS 文档链接或上传文件。官网身份由用户核对，不自动认证。

- 支持 UTF-8 TXT、MD、RST、JSON、HTML、DOCX、文字版 PDF。上传最多 8 MiB、提取最多 10 万字符；PDF 最多前 100 页，Linux 需 `poppler-utils`（`pdftotext`）。不执行宏或文档中的指令。
- 扫描 PDF / 图片 OCR、整站爬取、动态站点渲染尚未支持。网络使用公网 HTTPS 地址，逐次检查重定向并固定已校验 IP；代理的 fake-IP DNS 会被拒绝，可改用粘贴或文件。
- 「文档识别模型与 API 配置」支持选用已有本地模型，或接入兼容 Chat Completions 的 HTTPS 云端 API。连接测试是一次真实模型请求。模型识别最多 24000 字符，超出时拆分或取消识别，仅索引原文。
- 配置云端模型后，资料正文会发送至用户配置的服务。密钥沿用 `data/private/cloud-models.json`，目录 0700、文件 0600，公开接口不回传密钥。`data/` 不提交 Git。
- `source.md` 保存提取原文、游戏、版本和来源；`recognition.md` 保存模型摘要并标明待核对。可在本地库搜索引用行。未训练模型权重，未验证的摘要不是官方 API 事实。
- 代码库支持 Lua/Luau、GDScript、C#/C++ 等可读源文件；其他游戏的自动开发和打包适配尚在开发中。当前交付流水线仍面向 Minecraft 中国版。

任务和会议记录可移入回收站再恢复。运行中须先停止。此操作不会物理删除工程产物或破坏已有交付引用。
