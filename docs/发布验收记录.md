# SparkCraft V1.0 发布验收记录

日期：2026-09-27。面向 DGX Spark / Linux ARM64。

## 本轮完成

- 工作台支持想法、完整策划两种输入，提交后进入策划圆桌。参考代码库入口统一位于“代码库与知识 → 我的世界”，圆桌与编码默认检索所有导入代码库的相关片段。
- 七位圆桌成员新增美术虾绘，保留单独专业 Skill、OpenClaw Agent 和讨论模型路由。图像制作明确需要多模态模型。
- 美术多模态 API 配置包含地址、模型、协议与本机密钥保存。当前为接口预留，不发起图像生成请求；存在必需美术素材时禁止批准为完整制作。
- 修改意见创建关联原方案的新会议，保留旧记录；重新讨论后需要重新人工确认。策划整理数值与制作任务，人工批准后开始制作记录与任务派发。
- 完成包有下载提示弹窗。开屏文字和背景增加渐隐、轻微位移与模糊退场，保留原视觉风格和 logo 归位。
- 固定版本开发指南同步：600 个 Markdown 目录项，569 篇非空正文，31 个空占位，2,638,716 字符。无失败项。原官网在本机不可访问，使用网易开发者仓库参考快照；媒体仅保留原链接。

## 检查证据

- Python unittest：134 项，129 通过，5 项 Windows 专属检查在 Linux 跳过。
- 新增检查覆盖：多模态配置不回显密钥与导出拦截、新美术缺口不可批准、继续讨论保留父方案并没有沿用批准、跨代码库检索保留来源、指南缓存哈希复用及目录范围。
- Node 语法检查覆盖工作台、圆桌、交付、多模态配置与开屏动画脚本。
- 内置浏览器确认两种输入、七位成员、展开的多模态表单、Minecraft 知识库 569 篇正文状态；检查时未发现 console error/warn。
- 本机模型服务启动并返回 nemotron-3.5-lightning；美术 Agent 通过专用 OpenClaw 实际返回连接测试 JSON。该检查仅证明讨论连接，不是图像生成。

## 验证边界

交付测试使用确定性模型夹具和音频夹具验证审批、失败恢复、打包与凭据排除，未购买真实音频请求。未连接美术多模态服务，未生成真实美术素材，也未在 Minecraft 中国版客户端执行新模组。干净新设备的完整首次安装尚未重新实机验证；安装脚本有模拟分支测试及当前机器复用启动验证。

发布包只有源码、技能、示例、说明和启动脚本。模型、运行时、个人密钥、用户项目、聊天记录和第三方文档全文缓存不随包上传。首次部署及知识库同步需要网络。
