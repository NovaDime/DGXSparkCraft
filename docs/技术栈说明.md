# SparkCraft 技术栈说明

核对日期：2026-09-25。本表区分代码依赖、当前设备配置和部署预设，不将安装过的产品都计为本项目使用。

## NVIDIA 平台、SDK 与模型

| 组件 | 版本或标识 | 实际用途与验证边界 |
|---|---|---|
| NVIDIA DGX Spark / GB10 | Linux ARM64，本机检测为 NVIDIA GB10 | 承载本地模型推理；不代表任意 ARM64 设备都具备所需内存与GPU |
| NVIDIA 驱动 | 本机 580.173.02 | GPU 运行环境；是验证设备版本，不宣称所有部署必须固定此驱动 |
| NVIDIA CUDA Toolkit | 本机 `nvcc` 13.0 / V13.0.88 | 本机 GPU 开发环境；应用未直接编写 CUDA 核函数，推理内核运行依赖容器环境，宿主 Toolkit 版本不等于容器内版本 |
| NVIDIA Container Toolkit | 系统部署前提，版本未锁定 | 支持容器访问 NVIDIA GPU；安装脚本要求该系统能力事先可用 |
| NVIDIA Nemotron 主模型 | `nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-NVFP4` | 已在本机 vLLM 运行，提供圆桌、编码、审查及文档识别的文本推理；服务别名 `nemotron-3.5-lightning` |
| NVIDIA DSpark 辅助模型 | `nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-NVFP4-DSpark` | 一键部署脚本中的推测解码配置；当前运行容器未启用，不列为已实测加速成果 |

本项目没有直接集成 NVIDIA NeMo 训练 SDK、TensorRT-LLM、Riva 或 NIM，也没有执行微调。OpenClaw、vLLM、FlashInfer、Marlin 与 Docker 应分别按其真实项目归属描述，不能统称为 NVIDIA SDK。NemoClaw 即使在设备上存在，也不属于本应用当前必需的调用链。

## StepFun 阶跃星辰模型

| 模型 / 接口 | 用途 | 当前状态 |
|---|---|---|
| `stepaudio-3-gen-preview` | NPC 对话语音、物品与交互音效制作 | 后端适配器已实现，真实 API 音频生成尚未完成验收 |
| `POST /v1/audio/generate` | 按批准任务单提交音频请求 | 使用 `task=text_to_audio`，台词/角色与声音指令分开组织，音频响应校验后保存 |
| 其他兼容文本模型 | 可选角色路由、文档识别 | 由用户配置 Chat Completions 服务，不预设某个 StepFun 文本模型已经部署或使用 |

调音虾尾的圆桌讨论使用文本模型；音频生成是批准之后的独立调用。StepFun 密钥由用户在本机配置，仅供后端鉴权，不进入技能、会议提示词和模组代码。

## 应用与基础设施

| 层次 | 技术 / 固定版本 | 用途 |
|---|---|---|
| 推理服务 | `vllm/vllm-openai:v0.27.1` | 本机 OpenAI 兼容服务；Marlin、FP8 KV cache、前缀缓存等配置见部署说明 |
| Agent 网关 | OpenClaw `2026.9.4`；部署 Node `26.7.0` ARM64 | 项目专用 Gateway、角色工作区与模型路由 |
| 应用宿主 | Python `3.12+` | 调度、校验、文件写入、静态检查、部署工具；不是游戏脚本运行时 |
| HTTP 服务 | FastAPI `0.133.1`、Uvicorn `0.41.0` | 本机 API 与静态工作台 |
| 协议与请求 | Pydantic `2.13.4`、HTTPX `0.28.1` | 结构校验、模型及文档请求 |
| 持久化 | Python 标准库 SQLite | 会议、开发任务、知识索引与交付记录 |
| 音频处理 | SoundFile `0.13.1` 及其运行库 | 音频解码校验与 OGG/Vorbis 转换；不自动等价于游戏兼容验收 |
| 前端 | HTML、CSS、原生 JavaScript、SVG | 工作台、像素办公室、模型配置与代码预览；无必需前端构建服务 |
| 文档处理 | Python 标准库、可选 Poppler `pdftotext` | 文本、HTML、DOCX 与文字版 PDF；扫描图 OCR 尚未支持 |
| 开发环境 | VS Code、本地源码目录/ZIP | 人工继续开发与工程审阅；VS Code 不是运行后端的前提 |
| 游戏目标 | Minecraft 中国版基岩 1.24、网易 ModSDK | 客户端目标由用户指定；具体SDK版本及脚本运行时须逐项目核对 |

Python 依赖以根目录 `requirements.txt` 为可执行依据，部署版本以 `scripts/deploy_spark.py` 为准。

## 依据与实现位置

- NVIDIA 模型资料：[官方模型卡](https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-NVFP4)。本项目配方落在 `scripts/deploy_spark.py`，不将官方基准作为本项目实测。
- StepFun：[音频接口文档](https://platform.stepfun.ai/docs/en/api-reference/audio/generate)。实现为 `roundtable/audio_generation.py`。
- OpenClaw：[安装文档](https://docs.openclaw.ai/install)。项目配置生成器为 `scripts/setup_local_openclaw.py`。
- Minecraft：[官方 API](https://mc.163.com/dev/apidocs.html)、[开发指南](https://mc.163.com/dev/guide.html)。默认资料入口和证据状态由 `roundtable/official_knowledge.py` 管理。
