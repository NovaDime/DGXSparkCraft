# Minecraft 开发指南本地知识库

开发指南入口为 https://mc.163.com/dev/guide.html 。官网主站在当前环境无法直接读取，系统使用 MCNeteaseDevs/netease-bedrock-wiki 的固定版本 `894160bb5849e0b3c2be8d46351ca6e49f812fc8`，下载 `mcguide/` 下全部 Markdown。它是可追溯的参考快照，不是官网实时镜像，也不能替代目标客户端的兼容性验证。

本次同步范围：600 个 Markdown 路径，其中 569 篇非空正文、31 个空 README 占位文件，正文共 2,638,716 字符。图片、视频和附件不随此脚本下载；正文保留这些资源的原始相对链接，查看原文时请使用每篇顶部的仓库来源链接。文档中只有截图展示的字段，仍需查看原始图片，不能从文字缺失推断 API 不存在。

## 同步与恢复

在项目目录运行：

```bash
.venv/bin/python scripts/sync_minecraft_guide.py
```

或者进入“代码库与知识 → 我的世界”，点击更新官方知识库。首次需要联网。下载并发为 6；每篇失败最多重试 3 次；缓存通过 SHA-256 校验后复用。中途失败不会删除已取得的正文，重复运行会补齐失败项。目录截断、空目录、越界路径不会被标记为完整。

正文位于 `data/official-knowledge/sources/guide/guide/`。清单位于 `data/official-knowledge/sources/guide-manifest.json`，包括目录数量、每篇官方链接、快照来源、哈希和失败清单；状态位于 `data/official-knowledge/status.json`。CLI 与界面更新后都重建检索索引。

圆桌、编码与交付评审已经默认检索这份知识库，不需要手动选择代码库。每次只注入与当前问题相关的证据片段，而不是把 264 万字符塞进一次模型请求。模型参数没有因下载文档发生训练或改变。请按具体接口名称检索并核对引用路径。
